# Electric Vehicle Analytics Dashboard

## Project Overview
This Tableau dashboard analyzes electric vehicle adoption trends, manufacturer performance, CAFV eligibility, and model-wise insights using interactive visualizations and dashboard analytics.

## Features
- Electric Vehicle Adoption Analysis
- Manufacturer-wise Vehicle Insights
- CAFV Eligibility Tracking
- KPI Cards and Trend Analysis
- Interactive Dashboard Filters
- State-wise Vehicle Distribution Maps

## Tools Used
- Tableau
- Data Visualization
- Dashboard Design
- Data Analysis

## Key Skills Demonstrated
- Dashboard Development
- Data Visualization
- Business Intelligence
- KPI Reporting
- Interactive Filtering
- Trend Analysis

## Business Insights
- Identified top-performing EV manufacturers
- Analyzed EV adoption trends by year
- Tracked CAFV eligibility distribution
- Generated interactive visual reports for business insights

## Project Outcome
Developed an interactive Tableau dashboard to visualize electric vehicle trends and generate meaningful insights through dynamic analytics and visualization techniques.
